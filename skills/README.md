# Repo-Local Skills

Add a repo-local skill only when a workflow has stable invocation criteria,
inputs, outputs, checks, and stop conditions. Do not turn one-off fixes or
session history into skills.

Available skills:

- `audit-corpus-boundaries`: audit, explain, and—when writes are authorized—
  enforce universal backend/frontend feature boundaries, application-owned
  composition, and generic API versus Medusa acceptance ownership.
