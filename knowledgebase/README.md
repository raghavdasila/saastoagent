# Knowledgebase

Verified research findings, implementation notes, and reusable technical patterns for SaaStoAgent v0.1.

## Rules

1. Every claim should have citation or code/log proof
2. Include the date when the finding matters over time
3. Mark uncertain items clearly
4. Link findings to active plans when useful

## Structure

- `patterns/` for cross-cutting patterns
- Additional topic folders as needed
- Plan-specific research files when a plan needs dedicated research notes

## Current Focus Areas

- REST onboarding and action generation
- Workspace-as-agent architecture
- Structural REST retrieval and entity inference
- QA workflow patterns
