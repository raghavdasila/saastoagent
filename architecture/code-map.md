# SaaStoAgent Code Map

Last updated: 2026-06-10

This is the canonical subsystem-to-code map for SaaStoAgent v0.1. It is not a
per-file encyclopedia. Use it to find the code owner, architecture anchors, and
validation surface for a changed source file.

## How To Use This Map

- Start here when a task touches runtime, UI, API, or test code.
- Update the owning row when code ownership, public interfaces, or tests move.
- During closeout, list changed source files and either update the related
  architecture/test anchors or explicitly state that the anchors are unchanged.
- Run `python scripts/check_doc_coverage.py` before closeout for an advisory
  drift report.

## Closeout Rule

If a changed source file matches one of these rows, closeout must name the row
and say which of the architecture anchors and test anchors were updated or why
they did not need updates. `context.md` should link to this map when the current
state depends on source ownership, but it should not duplicate the table.
